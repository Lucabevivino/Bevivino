# RacePulse — Requirement Engineering & Design Project

Software Engineering 2 — Politecnico di Milano — A.Y. 2026-2027

**Student:** Luca Bevivino

## Overview

Requirement Analysis and Specification Document (RASD) and Design Document (DD)
for **RacePulse**, a distributed platform that collects Formula 1 session data
from [OpenF1](https://openf1.org/) and makes it available to heterogeneous
consumers (racing enthusiasts and third-party applications) through a GUI and
an API.

## Repository structure

- `RASD/` — Requirement Analysis and Specification Document (LaTeX)
  - `chapters/` — one `.tex` file per chapter
  - `alloy/` — Alloy formal model (`.als`)
  - `figures/` — UML and Alloy diagrams
- `DD/` — Design Document (LaTeX)
  - `chapters/` — one `.tex` file per chapter
  - `figures/` — architectural diagrams
- `DeliveryFolder/` — final versioned PDFs (`RASDv1.pdf`, `DDv1.pdf`)
